# MiniVS-Code

Mini VS Code w przeglądarce na telefon — minimalistyczny edytor notatek
w czerni i bieli, inspirowany VS Code.

## Funkcje

- 📁 Drzewo plików i folderów z zakładkami, zapisem w `localStorage`
- ✏️ Tryb edycji struktury: zmiana nazw, przenoszenie, sortowanie
- 🔢 Numeracja wierszy (z obsługą zawijania linii) + pasek stanu (Ln/Kol, słowa, status zapisu)
- ⌕ Szukanie w pliku (Ctrl+F) oraz globalne wyszukiwanie frazy we wszystkich notatkach (🔍 / Ctrl+Shift+F)
- 👁 Podgląd Markdown dla `.nota`, `.pomysl`, `.todo` i podświetlanie kodu dla `.kod`
- 🗑️ Kosz z przywracaniem usuniętych plików
- 🕘 Automatyczne, lokalne kopie zapasowe z możliwością przywrócenia
- 💾 Eksport / import JSON (z potwierdzeniem i kopią bezpieczeństwa)

Wszystko przechowywane lokalnie w przeglądarce (nic nie trafia na serwer).
